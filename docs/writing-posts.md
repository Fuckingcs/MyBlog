# 如何发文章

在 GitHub 仓库中打开 `src/content/posts/`，点击 **Add file → Create new file**。文件名建议使用英文小写字母和连字符，例如 `my-first-note.md`；它也会成为文章的网址。

将下面的内容复制到新文件中，改好标题、日期、栏目和正文，然后提交。`category` 只能写 `essays`（随感）或 `notes`（笔记）。

````md
---
title: "我的第一篇笔记"
date: 2026-09-29
category: notes
---

这里写文章的第一段。卡片摘要会自动取第一段可读文字，并在页面上显示最多两行。

## 小标题

继续写正文。支持 Markdown 的列表、引用、代码块和图片。
````

## 图片

需要配图时，先把图片上传到 `public/images/文章名/`，再按上面的写法在文章中引用。卡片会自动使用**正文中的第一张图片**作为封面；这张图片在正文中仍会显示。没有图片时，卡片使用灰白渐变。

图片地址要以 `/images/` 开头，部署时会自动适配 GitHub Pages 的仓库路径。尽量为图片写有意义的说明文字。

## 更新与检查

在 GitHub 网页上编辑并提交 Markdown 文件后，Actions 会自动重新发布网站。若文章标题、日期或栏目填写有误，构建会失败；可在仓库的 **Actions** 页面查看错误，再修改文件。
